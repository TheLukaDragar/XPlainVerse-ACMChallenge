## 2. Retrain strategy (decided + launched today)

Goal: maximize **macro F1 / real F1**. Three traps and the fixes:

### Trap A — data balance
Train = 130k real / 320k fake (71% fake). Old `manifest_train_balanced` (260k) uses all
reals but **discards 190k fakes**. Naively using all 450k biases toward fake → crushes
real recall.
**Fix:** `manifest_train_full_balanced.parquet` — keep **all 320k fakes** (diversity that
helps test robustness), **oversample reals to 320k** → **640k, 1:1**. Augmentation keeps
repeated reals from being pure duplicates. Works with existing DDP `DistributedSampler`.

### Trap B — objective / checkpoint selection
Training selected best checkpoint by **AUC** and reported a **fake-F1** threshold —
neither matches Task-1.
**Fix:** compute macro F1 / real F1 + a **macro-F1-optimal threshold** every epoch;
select best checkpoint via `--select-metric macro_f1`.

### Trap C — deploy calibration
**Fix:** still calibrate the deploy threshold on **full 110k val for macro F1**
(`sweep_pass1_threshold.py`), never from a val slice. Prior sweep showed thr **0.11**
gives macro F1 **0.864** vs **0.857** at the deployed 0.084.

### Warm start
Init from Bombek weights (`--init-bombek bombek`), 3 epochs, lower LoRA LR (3e-5).

## 4b. Full run — RESULT (lateral move, not a win)

Run finished: best val macro F1 **0.8602** (10k slice, epoch 2). Full **110k** val eval

|---|---|---|---|
| AUC | **0.9403** | 0.9359 | 0.9395 |
| macro F1 @best thr | 0.8601 | 0.8603 | **0.8640** |
| real F1 | 0.8468 | 0.8512 | — |
| real / fake acc @macro | 0.843 / 0.877 | — | — |
| best thr | 0.025 | 0.11 | 0.082 |

**Verdict:** slightly better AUC and a more balanced real/fake split, but **macro F1 is
flat (~0.860)** and the old model **with flip TTA still wins (0.864)**. Full-balanced +
Bombek-init + macro-F1 selection alone did **not** break the bottleneck.

Do **NOT** spend a CodaBench slot on this — no clear delta over the deployed model.

### What this tells us
- The ceiling for a single SigLIP2+DINOv2 LoRA model on this val is ~0.86 macro F1
  regardless of data-balance tricks. The remaining gains are not in this recipe.
- Real F1 / real recall is sticky around 0.84–0.85 — the limiting factor.

## 5. Next steps (after this run finishes)

### Highest-ROI now (since retrain was a wash)
1. **Score-ensemble OLD + NEW models** — they were trained on different data mixes
   (260k undersampled vs 640k full-balanced) and have different operating points
   (thr 0.11 vs 0.025), so their errors should be partially decorrelated. Average
   `p_fake` on full val, re-calibrate macro-F1 threshold. This is the most likely way
   to actually clear 0.864.
2. **Add flip TTA to the new model** (`eval_ensemble_tta.py`) — old model gained
   +0.004 macro F1 from it; cheap to try and stacks with (1).


3. Only if (1)+(2) clear the baseline → recut test predictions and **one CodaBench
   submit** (10 total submissions; spend them on meaningful detection deltas only).
4. Lower priority A/B: focal `alpha=0.5`, a third diverse seed, or adding SigLIP-Giant
   as the SigLIP tower in the **same dual-tower** recipe — not bigger solo backbones.
